# Telegram Voice AI Bot (STT + TTS)

Мультимодальный голосовой бот для Telegram, работающий в двух режимах: распознавание речи (голос -> текст) и синтез речи (текст -> голос).

## 🚀 Ключевые особенности и архитектурные решения

### 1. Переход на локальный синтез речи (Silero TTS)
**Проблема:** Изначально бот использовал облачный сервис Microsoft Edge TTS. Однако в 2026 году Microsoft ужесточила политику безопасности, ввела новые токены и начала блокировать запросы с IP-адресов VPS/дата-центров (ошибка `NoAudioReceived`). Использование прокси не решало проблему полностью из-за ограничений WebSocket.
**Решение:** Синтез речи был полностью перенесен на локальную нейросеть **Silero TTS**.
**Преимущества:**
*   **100% стабильность:** Бот больше не зависит от блокировок Microsoft.
*   **Конфиденциальность (152-ФЗ):** Текст не отправляется на сторонние сервера.
*   **Zero-cost:** Нулевые затраты на API.
*   **Офлайн-режим:** Синтез работает без доступа к интернету.

### 2. Распознавание речи
Для перевода голоса в текст используется локальная модель **faster-whisper** (модель `small`, `int8`). Это обеспечивает высокую скорость работы даже на CPU без необходимости в дорогостоящих GPU.

### 3. Удобный пользовательский интерфейс
*   Реализована система выбора голоса (мужские и женские голоса Silero) через Inline-клавиатуру.
*   Добавлена постоянная клавиатура с основными командами.
*   Реализован асинхронный статус обработки (бот моментально пишет "Секундочку, синтезирую...", чтобы пользователь не думал, что бот завис).
*   К голосовым сообщениям прикрепляется текстовая расшифровка (caption).

## 🛠 Стек технологий
*   Python 3.12
*   `python-telegram-bot` (v21+)
*   `faster-whisper` (STT)
*   `Silero TTS` + `torch` (TTS)
*   `ffmpeg` (конвертация аудио в ogg/opus)
